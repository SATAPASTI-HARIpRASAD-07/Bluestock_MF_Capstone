# Bluestock Fintech Internship Capstone Project Summary

**Project Name**: Nifty 100 Financial Intelligence Platform  
**Organization**: Bluestock Fintech Pvt. Ltd.  
**Domain**: Financial Engineering, Data Analytics, Web Development  

---

### Executive Deliverables Summary

- **Nifty 100 Universe**: Analyzed **92 companies** across **11 broad sectors**.
- **Datasets Ingested**: Processed **12 authoritative datasets** (Sectors, Peer Groups, Financial Ratios, Market Cap, Stock Prices, Qualitative Analysis, Pros & Cons, Financial Statements, Documents Repository).
- **SQLite Database**: Built `db/nifty100.db` with **12 normalized tables** and **10,000+ total rows**.
- **Financial KPI Engine**: Computed **50+ Financial KPIs** covering Profitability, Solvency, Efficiency, Cash Flow, Per Share, 1Y..10Y CAGRs, and Valuation Multiples.
- **REST API Service**: Implemented **16 FastAPI endpoints** with interactive OpenAPI `/docs`.
- **Streamlit Dashboard**: Multi-page dashboard with **8 interactive screens**.
- **Automated Reporting**: Generated **2-Page ReportLab PDF Tear Sheets** in `reports/company/` and formatted **openpyxl Excel exports** in `outputs/`.
- **Quality Assurance**: Passed **20 automated pytest tests** covering ETL, ratios, edge cases, API routers, and pipeline regression.
